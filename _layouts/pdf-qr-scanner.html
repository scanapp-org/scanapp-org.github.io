What this reader supports

Use an unprotected PDF up to 20 MB and 200 pages. Select and scan one page at a time; this tool reads one QR code from that page. Password-protected or damaged PDFs cannot be opened here. Very small, blurred, or obscured QR codes may not be readable.

For multiple codes on one page, crop a screenshot around each code and use the image scanner. For help, see the PDF scanning guide.
