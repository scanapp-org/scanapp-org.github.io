ScanApp work-order PDF practice kit

Start with the guide:
https://scanapp.org/supports/prepare-work-order-pdfs-locally

demo-job-1001.pdf and demo-job-1002.pdf are original synthetic source documents.
The first has two pages and the second has one. QR codes contain only demo job IDs.
No real people, customer records, external QR links or live service data are included.

reference-merged.pdf and reference-job-1001.pdf are reference outputs built with
the same local PDF transformation core used by ScanApp's PDF workspace.
See expected-order.txt for page order and QR contents.

The guide teaches manual merge, review, extraction and selected-page QR reading.
It does not demonstrate automatic document classification, naming, CSV extraction,
business-system integration or verification that a work order is authentic.

These examples are provided under this repository's license.
