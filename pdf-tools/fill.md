## Fill an interactive PDF form
Open a supported PDF and expand Fill document form fields. Edit text, checkbox and choice fields for the selected source document. Read-only fields cannot be changed. Export flattens supported fields so their values become visible page content.

## Write on a flat form
Choose Add text, enter your answer and click its location on the preview. Added text uses a standard font with Western European character support. It does not replace existing embedded text or automatically fit into every box.

## Draw a visual signature
Choose Draw signature and draw on the page. Undo removes a stroke if you need to retry. This places a visual mark; it does not provide identity verification, a signing certificate or a cryptographic digital signature. Documents with digital-signature fields are rejected to avoid misleading edits.
