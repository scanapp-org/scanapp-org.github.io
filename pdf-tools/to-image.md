## Export a PDF page as an image
Open a PDF and select a page. Choose PNG or JPG under Image format, then select Export selected page as image. Move to another page to export it separately.

## PNG or JPG?
PNG is useful for sharp lines and text. JPG can make photographic pages smaller but uses lossy compression. Output has a white background. Rendering uses up to twice the PDF point dimensions, capped at 2400 pixels on the longer side.

## Images do not contain selectable PDF text
Image export rasterizes the selected page. Use Download edited PDF instead if you need a PDF retaining its underlying page content. This tool does not currently download all pages as a ZIP.
