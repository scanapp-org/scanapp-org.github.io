## Extract pages into a new PDF
Open the source PDF and enter the pages you want in Export pages. For example, `1, 3-5` includes the first page and pages three through five. Download edited PDF to save that subset. Ranges refer to the current workspace order, after any page moves or deletions.

## Split into several documents
Export one range, change the range and export the next document. Repeated page numbers are included once. Empty input exports all pages; invalid or descending ranges are rejected.

## Preserve page content
Page extraction copies PDF page content rather than turning every page into an image. Supported form fields become flat visible content in the output. Review each exported file.
